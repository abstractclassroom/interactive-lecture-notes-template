## Subset containment

A set $A$ is a **subset** of a set $B$ when every element of $A$ is also an element of $B$. We write $A \subseteq B$.

If $A = \{1,3\}$ and $B = \{1,2,3\}$, then $A \subseteq B$.

If even one element of $A$ is missing from $B$, then $A$ is **not** a subset of $B$. We write $A \nsubseteq B$.

For $C = \{1,4\}$ and $B = \{1,2,3\}$, the element $4$ provides a counterexample, so $C \nsubseteq B$.

Every set is a subset of itself because every element in the set is necessarily contained in that same set. Therefore, $A \subseteq A$ for every set $A$.
