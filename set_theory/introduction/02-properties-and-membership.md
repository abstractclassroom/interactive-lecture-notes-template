## Order, duplicates, and membership

The order of a set's elements does not matter, and repeating an element does not create a new element.

$$
\{1,2,3\} = \{3,2,1\} = \{1,1,2,3,3\}
$$

The symbol $\in$ means “is an element of.” The symbol $\notin$ means “is not an element of.”

For $A = \{2,4,6\}$, we have $4 \in A$ and $5 \notin A$.

Sets may also be elements of other sets. If $B = \{1, \{2,3\}\}$, then $1 \in B$ and $\{2,3\} \in B$. However, $2 \notin B$ because $2$ is inside the nested set rather than directly inside $B$.
