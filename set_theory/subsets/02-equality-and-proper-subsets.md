## Equality through bidirectional containment

Two sets are equal precisely when each is a subset of the other.

$$
A = B \quad \Longleftrightarrow \quad A \subseteq B \text{ and } B \subseteq A
$$

This is called **bidirectional containment**. It is a standard way to prove that two sets are equal.

When $A \subseteq B$ but $A \ne B$, $A$ is a **proper subset** of $B$. We write $A \subsetneq B$.

For example, $\{1,2\} \subsetneq \{1,2,3\}$. The containment is true, but the sets are not equal because the second set contains an additional element.
