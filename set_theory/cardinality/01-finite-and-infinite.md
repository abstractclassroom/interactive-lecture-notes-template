## The size of a set

The **cardinality** of a set is the number of distinct elements it contains. Common notation includes $|A|$ and $\operatorname{card}(A)$.

If $A = \{a,b,c\}$, then

$$
|A| = \operatorname{card}(A) = 3.
$$

A set is **finite** when its elements can be completely counted and the count ends at a natural number. A set is **infinite** when no finite natural number gives its cardinality.

The natural numbers $\mathbb{N} = \{0,1,2,3,\ldots\}$ form an infinite set. Their cardinality is written $|\mathbb{N}| = \aleph_0$.
