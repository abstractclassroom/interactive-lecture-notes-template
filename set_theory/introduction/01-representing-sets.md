## Three ways to represent a set

A **set** is a collection of distinct objects. The objects in a set are called its **elements**.

Consider the even positive integers less than $10$. We can describe the same set in three common ways.

| Representation | Example |
| --- | --- |
| Sentence | The set of even positive integers less than $10$ |
| Roster | $E = \{2, 4, 6, 8\}$ |
| Set-builder | $E = \{x \in \mathbb{Z}^{+} \mid x < 10 \text{ and } x \text{ is even}\}$ |

Roster notation lists the elements. Set-builder notation states the rule an object must satisfy to belong to the set.
