# Subsets and Proper Subsets

A set $A$ is a subset of a set $B$ when every element of $A$ is also an element of $B$. We write this relationship as $A \subseteq B$.

Let $A = \{1, 2\}$ and $B = \{1, 2, 3\}$. Every member of $A$ appears in $B$, so $A \subseteq B$.

A proper subset contains fewer elements than the set containing it. Because $A \subseteq B$ and $A \ne B$, we may write $A \subset B$.

Every set is a subset of itself. The empty set is a subset of every set.

## A useful test

To decide whether $A \subseteq B$, inspect each element of $A$. The relationship is false as soon as one element of $A$ is missing from $B$.
